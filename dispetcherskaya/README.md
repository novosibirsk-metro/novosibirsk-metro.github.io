# Метро НСК: Диспетчерская

Живая модель Новосибирского метрополитена: обе линии, 14 станций, 26 составов. Лежит отдельно от схемы и игр и с ними не связана.

Адрес: https://novosibirsk-metro.github.io/dispetcherskaya/

## Что внутри

- **Пути.** Настоящая геометрия путей из OpenStreetMap (© участники OSM, ODbL): стрелки, тупики, съезды, платформы, выходы, электродепо «Ельцовское», метромост.
- **Подложка.** «Спутник» (снимки Esri World Imagery) или «Схема».
- **Движение по графику.**
  - Часы работы 6:00–24:00, интервалы по часам.
  - Оборот в тупиках Заельцовской и Площади Маркса, у платформы — на Площади Гарина-Михайловского и Золотой Ниве.
  - Выпуск из депо и возврат в депо идут по настоящим путям.
- **Распоряжения диспетчера** — нажмите на любой состав:
  - отправить в депо;
  - отправить в отстой;
  - отправить на обкатку;
  - выпустить на любую линию;
  - перевести на другую линию через депо.
- **Нештатные ситуации** по мотивам реальных случаев 2013–2026 годов.
- **Паспорта станций** со ссылками на источники.

Положение поездов рассчитано по графику: открытых данных о движении поездов метрополитен не публикует.

Один HTML-файл без сборки. Шрифты подгружаются с Google Fonts, спутниковые снимки — с сервера Esri, остальное внутри файла.
