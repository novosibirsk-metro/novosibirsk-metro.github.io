# Игры

Симуляторы участков Новосибирского метрополитена. Лежат отдельно от схемы и с ней не связаны.

- `berezovaya-zolotaya/` — перегон «Берёзовая роща» — «Золотая Нива»: камера съездов, однопутный участок,
  оборот у платформы Золотой Нивы, ручной перевод стрелок, светофоры и итоги смены.
  Адрес: https://novosibirsk-metro.github.io/games/berezovaya-zolotaya/

Каждая игра — один HTML-файл без сборки. Шрифты подгружаются с Google Fonts, остальное внутри файла.
